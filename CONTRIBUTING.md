# Contributing

Thanks for helping the CSIA club! Keep the repo **short, accurate, and beginner-friendly**.

## Golden rules

1. **Never invent** a challenge, URL, flag, or result.
2. **Link, don't copy** challenge files or text from other platforms.
3. A writeup must match the **exact** linked challenge.
4. If you did not personally solve it, mark the writeup **Unverified** or **Source-verified** (see below).
5. Only legal, authorized activities.

## Verification labels for writeups

| Label | Meaning |
|---|---|
| ✅ **Verified** | The author solved this exact challenge and checked every step. |
| 🟡 **Source-verified** | Steps are checked against the platform's official solution, but not re-run by the author. |
| ⚠️ **Unverified** | Not checked. Do not merge without review. |

## Challenge folder template

```
challenge-name/
├── README.md    # title, difficulty, platform, URL, concepts, time, tools, videos, spoiler warning
├── hints.md     # 2-4 progressive hints
└── writeup.md   # full step-by-step solution (what / why / command / output / next)
```

## Style

- English first, with short natural Moroccan Darija for key ideas.
- Short paragraphs. Tables and Mermaid diagrams where they help.
- YouTube: only link a video you checked. Otherwise use a YouTube **search** link.
- Dark navy `#101827`, cyan `#00D4FF`, purple `#805AD5`.

## Pull request checklist

- [ ] Links open and point to the intended page
- [ ] Commands tested
- [ ] No fabricated flags
- [ ] Renders correctly on GitHub (desktop + mobile)
