# CTF Glossary

| Term | Simple meaning | الدارجة |
|---|---|---|
| **CTF** | Capture The Flag: a security game. | لعبة أمن معلوماتي |
| **Flag** | Hidden text proving you solved a challenge. | الكود اللي كتلقى |
| **Jeopardy** | CTF format with independent challenges. | تحديات مستقلة |
| **Attack-Defense** | Teams defend and attack at the same time. | هجوم ودفاع |
| **Writeup** | A document explaining how a challenge was solved. | شرح الحل |
| **Payload** | The input you send to trigger a bug. | الـ input اللي كتصيفط |
| **Vulnerability** | A weakness in a system. | ثغرة |
| **Exploit** | Using a vulnerability to get a result. | استغلال الثغرة |
| **Enumeration** | Collecting information about a target. | جمع المعلومات |
| **Recon** | Early investigation of a target. | الاستكشاف |
| **HTTP** | The protocol browsers use to talk to websites. | بروتوكول الويب |
| **Cookie** | Small data stored by your browser for a site. | كوكي |
| **SQL** | Language used to talk to databases. | لغة قواعد البيانات |
| **SQL injection** | Changing a SQL query by sending crafted input. | حقن SQL |
| **UNION** | SQL keyword that combines results of two queries. | كيجمع نتائج |
| **Burp Suite** | Tool to intercept and edit web requests. | أداة لتعديل الـ requests |
| **Encoding** | Changing data format (Base64, hex). Not secret. | ترميز |
| **Encryption** | Scrambling data with a key. | تشفير |
| **Hash** | One-way fingerprint of data. | بصمة |
| **Metadata** | Data about data (author, date, GPS). | بيانات وصفية |
| **OSINT** | Intelligence from public sources. | معلومات مفتوحة المصدر |
| **Shell** | A command interface on a system. | واجهة الأوامر |
| **Pwn** | Slang for exploiting binaries. | استغلال البرامج |
| **Encoding** | Changing data format (Base64, hex). Reversible, not secret. | ترميز |
| **XOR** | Bitwise operation; core of symmetric crypto; its own inverse. | عملية XOR |
| **Key (crypto)** | The secret needed to decrypt. | المفتاح |
| **RSA** | Public-key crypto based on hard-to-factor numbers. | تشفير RSA |
| **Modular arithmetic** | "Clock" math: remainder after division. | حساب بالباقي |
| **Known plaintext** | Knowing part of the message (e.g. the flag prefix) to break a cipher. | نص معروف |
| **Magic bytes** | First bytes of a file that reveal its true type. | بايتات التعريف |
| **EXIF / metadata** | Data about a file (author, GPS, date). | بيانات وصفية |
| **pcap / pcapng** | A recorded capture of network traffic. | تسجيل الشبكة |
| **Follow TCP stream** | Reassemble one conversation in Wireshark. | تتبع المحادثة |
| **Carrier / payload** | In stego, the normal file / the hidden data. | الغطاء / السر |
| **LSB** | Least Significant Bit; hides data in the last bit of each pixel. | البيت الأخير |
| **Spectrogram** | A picture of sound frequencies; can hide text. | طيف الصوت |
| **Disassembly** | Machine code shown as assembly instructions. | تفكيك للأسمبلي |
| **Decompiler** | Turns a binary back into readable pseudocode (Ghidra). | مُفكِّك للكود |
| **Debugger** | Runs a program step by step (GDB). | مُنقِّح |
| **Stack** | Memory region holding local variables and return addresses. | المكدس |
| **Buffer overflow** | Writing past a buffer to overwrite nearby memory. | فيضان الـ buffer |
| **Return address** | Stored location a function jumps back to; a pwn target. | عنوان الرجوع |
| **Offset** | Byte distance from a buffer to the return address. | المسافة بالبايت |
| **ret2win** | Overwriting the return address to call a flag-printing function. | القفز لـ win |
| **pwntools** | Python library for writing exploits. | مكتبة الاستغلال |
| **checksec** | Shows which binary protections are enabled. | فحص الحمايات |
| **OSINT** | Open Source INTelligence: using public information. | معلومات مفتوحة المصدر |
| **Reverse image search** | Finding where/what an image is from. | بحث بالصورة |
| **Geolocation** | Pinning a photo's real-world place. | تحديد الموقع |
| **Google dorking** | Advanced search operators to find exposed info. | بحث متقدم |
| **Pivot** | Using one finding to launch the next search. | الانتقال بين الأدلة |
| **Wayback Machine** | Archive of old versions of web pages. | أرشيف الويب |
