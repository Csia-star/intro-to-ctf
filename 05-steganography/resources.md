# Steganography: Resources

- [Aperi'Solve](https://aperisolve.fr) (browser; runs many stego tools at once — start here)
- [picoCTF picoGym, Forensics category](https://play.picoctf.org/practice?category=4) (stego challenges live here)
- [zsteg (GitHub)](https://github.com/zed-0xff/zsteg) (LSB detection for PNG/BMP)
- [steghide (official)](https://steghide.sourceforge.net/) (passphrase stego for JPG/WAV)
- [Audacity](https://www.audacityteam.org) (spectrogram view for audio challenges)
- [CTF101: Steganography](https://ctf101.org/forensics/what-is-stegsolve/) (free reading)
- [StegOnline](https://georgeom.net/StegOnline/upload) (browser bit-plane viewer, alternative to stegsolve)

> Reminder: run `strings`, `exiftool`, and `binwalk` **before** reaching for these. The simple check often wins.
